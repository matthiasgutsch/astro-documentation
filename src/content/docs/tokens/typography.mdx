## Typography Tokens

Typography tokens define the text styles used across all components and layouts.

---

## Font Family

| Token         | Value                                            |
| ------------- | ------------------------------------------------ |
| `--font-sans` | `Inter, ui-sans-serif, system-ui, sans-serif`    |
| `--font-mono` | `ui-monospace, SFMono-Regular, Menlo, monospace` |

---

## Font Size

| Token         | Value             | Example                                                 |
| ------------- | ----------------- | ------------------------------------------------------- |
| `--text-xs`   | `0.75rem / 12px`  | <span style="font-size:0.75rem">Aa — Extra small</span> |
| `--text-sm`   | `0.875rem / 14px` | <span style="font-size:0.875rem">Aa — Small</span>      |
| `--text-base` | `1rem / 16px`     | <span style="font-size:1rem">Aa — Base</span>           |
| `--text-lg`   | `1.125rem / 18px` | <span style="font-size:1.125rem">Aa — Large</span>      |
| `--text-xl`   | `1.25rem / 20px`  | <span style="font-size:1.25rem">Aa — XL</span>          |
| `--text-2xl`  | `1.5rem / 24px`   | <span style="font-size:1.5rem">Aa — 2XL</span>          |
| `--text-3xl`  | `1.875rem / 30px` | <span style="font-size:1.875rem">Aa — 3XL</span>        |

## Font Weight

| Token             | Value | Example                                            |
| ----------------- | ----- | -------------------------------------------------- |
| `--font-normal`   | `400` | <span style="font-weight:400">Regular text</span>  |
| `--font-medium`   | `500` | <span style="font-weight:500">Medium text</span>   |
| `--font-semibold` | `600` | <span style="font-weight:600">Semibold text</span> |
| `--font-bold`     | `700` | <span style="font-weight:700">Bold text</span>     |

## Line Height

| Token               | Value   | Usage             |
| ------------------- | ------- | ----------------- |
| `--leading-tight`   | `1.25`  | Headings          |
| `--leading-snug`    | `1.375` | Subheadings       |
| `--leading-normal`  | `1.5`   | Body text         |
| `--leading-relaxed` | `1.625` | Long-form content |

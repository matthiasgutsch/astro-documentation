## Color Tokens

Color tokens define the palette used across all components. They are split into **primitive** tokens (raw values) and **semantic** tokens (purpose-driven aliases).

## Semantic Colors

| Token                | Maps to              | Usage                          |
| -------------------- | -------------------- | ------------------------------ |
| `--color-primary`    | `--color-blue-500`   | Main brand actions             |
| `--color-success`    | `--color-green-500`  | Positive states, confirmations |
| `--color-warning`    | `--color-yellow-500` | Cautionary states              |
| `--color-danger`     | `--color-red-500`    | Destructive actions, errors    |
| `--color-surface`    | `--color-gray-100`   | Page and card backgrounds      |
| `--color-text`       | `--color-gray-900`   | Body text                      |
| `--color-text-muted` | `--color-gray-500`   | Secondary / helper text        |

## Spacing Tokens

Spacing tokens define a consistent scale for margins, paddings, gaps, and layout dimensions throughout the design system.

## Usage Guidelines

| Context                   | Recommended token   |
| ------------------------- | ------------------- |
| Icon padding              | `--space-2` (8px)   |
| Button horizontal padding | `--space-4` (16px)  |
| Card padding              | `--space-6` (24px)  |
| Section gap               | `--space-8` (32px)  |
| Page margin               | `--space-12` (48px) |

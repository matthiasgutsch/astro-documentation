## Variants

| Prop         | Type      | Values                                                                           | Default   |
| ------------ | --------- | -------------------------------------------------------------------------------- | --------- |
| `severity`   | `string`  | `primary` · `secondary` · `success` · `info` · `warning` · `danger` · `contrast` | `primary` |
| `value`      | `string`  | any string                                                                       | —         |
| `icon`       | `string`  | PrimeIcons class e.g. `pi pi-check`                                              | —         |
| `rounded`    | `boolean` | `true` · `false`                                                                 | `false`   |
| `size`       | `string`  | `small` · `large`                                                                | —         |
| `style`      | `string`  | inline styles                                                                    | —         |
| `styleClass` | `string`  | CSS class names                                                                  | —         |

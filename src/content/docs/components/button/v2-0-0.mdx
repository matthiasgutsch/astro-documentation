### Description

Button — 4 variants (accent, primary, secondary, danger) × 3 sizes (small, medium, large) × 4 states (idle, hover, pressed, disabled). Icon slots: `icon-left`, `icon-right`.

### What changed in v3.0.0

| Change           | v2.0.0                        | v3.0.0                             |
| ---------------- | ----------------------------- | ---------------------------------- |
| Design tokens    | bound via component variables | full semantic token mapping        |
| Icon slot sizing | fixed 16px                    | size-responsive (S→16, M→20, L→24) |
| Disabled style   | opacity                       | token-driven                       |

</TabItem>

<TabItem label="Design">

### Variants

| Variant   | Description                      |
| --------- | -------------------------------- |
| Accent    | Highest-emphasis action.         |
| Primary   | High-emphasis action.            |
| Secondary | Medium-emphasis, outlined style. |
| Danger    | Destructive action.              |

### Sizes

| Size | Height |
| ---- | ------ |
| S    | 36px   |
| M    | 44px   |
| L    | 52px   |

</TabItem>

<TabItem label="Develop">

### Usage

```html
<button class="btn btn-primary btn-md">Label</button>
<button class="btn btn-accent btn-lg">Label</button>
<button class="btn btn-danger btn-sm">Delete</button>
```

### Design Tokens

Tokens were introduced in v2.0.0 and expanded in v3.0.0.
